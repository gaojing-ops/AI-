# 目录结构

- 根目录 `*.py`、`启动小说工具.pyw`：桌面、命令行及业务模块。
- `maintenance/`：通用维护工具。
- `scripts/`：明确选择后才执行的独立工具脚本。
- `skills/`：运行时 JSON 技能。
- `templates/`：通用流派模板。
- 根目录 `plot/`、`characters/`、`world_building/`：空白设定模板及说明。
- `tests/`：独立离线测试，样例不是实际小说项目。
- `docs/`：通用使用和维护说明。
- `projects/`：新书项目容器，初始仅保留 `.gitkeep`。
- `.tools/`：本机配套依赖，不提交 GitHub。
- `config.json`：本机配置，不提交 GitHub。
- `.runtime/`：使用后产生的运行状态，不提交 GitHub。
- 本机 `LocalAppData/NovelTool/job_locks/`：操作系统任务锁保护文件，仅用项目路径摘要命名；不存稿件，也不复制到项目。测试使用临时目录并自动清理。

每本书的正文、封面、设定、收据、日志和历史统一放入其独立项目目录。工具根目录不存放单书进度、临时审稿脚本或研究下载。

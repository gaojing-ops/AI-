# 使用说明

## 启动和新建

使用 Python 3.14，双击根目录 `启动小说工具.pyw`。本地依赖位于 `.tools/`；新电脑按 `requirements.txt` 安装依赖。模型设置参考 `config.example.json`，实际凭据留在本机。

点击“新建一本”，选择 `projects/项目名/` 并填写书名、设定及目标。每本书使用自己的 `project_config.json`；不要把某本书的设定写入通用模板。

开始生成后，工具依次处理候选、检查、有限修复、正式提交和记忆维护。点击“暂停”保留断点；恢复前查看停止原因和剩余预算。预算耗尽需显式续开，不会因重启或更换模型自动重置。

## 文件含义

- `rewrite_staging/`：候选和修订稿。
- `output/`：经过正式提交的正文。
- `publish/`：通过镜像检查的本地发布副本。
- `plot/`：大纲、正史、状态增量和提交收据。
- `logs/`、`history/`：项目日志和历史。

“最新稿”能查看或复制，不表示已经提交或在平台发布。确认续写起点时核对正式目录和收据。

## 命令行

只读查看状态和体检：

```powershell
py -3.14 -X utf8 -B novel_cli.py status --project "projects/项目名"
py -3.14 -X utf8 -B novel_cli.py doctor --project "projects/项目名"
```

`doctor` 不调用模型，不恢复事务或改写配置；输出 JSON，失败返回退出码 2。仅在需要核查该项目时运行。

正式批次指定已知正式尖端及终点：

```powershell
py -3.14 -X utf8 -B novel_cli.py run --project "projects/项目名" --expected-latest 0 --to 3 --execute
```

不带 `--execute` 不执行生成。实际生成可能产生模型费用，开始前设置项目预算。

连续正式尾段重写使用事务和回滚保护；缓存只有在正文、前置状态、模型、配置、上下文及代码绑定一致时才复用。遇到明确失败时保留现场，按具体原因修复。
